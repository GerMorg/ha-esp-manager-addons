# Entwicklungsprotokoll

1. Vor Änderungen alle Dateien in `project_memory` lesen.
2. Betroffene Capability-IDs bestimmen.
3. API, UI und Tests gemeinsam ändern.
4. Vorher/Nachher-Vergleich für Routen, UI-Controls, Agent-API, Schema und Datenpfade durchführen.
5. Historische Ledgers nur ergänzen. Korrekturen als neuen, ersetzenden Eintrag anlegen.
6. Fehlende Pflichtfunktion blockiert eine Ausgabe.
7. Das vollständige `project_memory` in jedes Repository aufnehmen.
