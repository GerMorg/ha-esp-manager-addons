# Changelog

## 0.5.2
- Projektimport zeigt jetzt verständliche Erfolgs- und Fehlermeldungen.
- Vor dem Import wird geprüft, ob eine ZIP-Datei ausgewählt wurde.
- Für den neuen Projektnamen wird ein Vorschlag aus dem ZIP-Dateinamen erzeugt.
- Namenskonflikte werden klar gemeldet.
- ZIP-Dateien werden auf Lesbarkeit und beschädigte Einträge geprüft.
- Import erfolgt zunächst in ein temporäres Verzeichnis und wird erst nach vollständiger Validierung veröffentlicht.
- Unvollständige Importversuche werden aufgeräumt.
- Das importierte Projekt wird nach Erfolg automatisch geöffnet.
