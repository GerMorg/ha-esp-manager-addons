ESP MANAGER PROJEKTUEBERGABE
============================
Stand: 0.5.2 / 0.5.2-dev

ZIELBILD
Home-Assistant-Add-on zur zentralen Verwaltung von Arduino-C++-basierten ESP-Projekten. Die Anwendungslogik bleibt im Benutzerprojekt; der ESPManager-Agent stellt langfristig WLAN, MQTT, Diagnose, Logs und OTA zentral bereit. Erster späterer Hardwaretest bleibt der Sagemcom/Netz-Niederoesterreich-M-Bus-Zaehler-ESP.

BESTEHENDER FUNKTIONSUMFANG
- Projektanlage, Editor und geschützte Systemdateien
- Projekt-Einstellungen sowie PlatformIO-Expertenbereich
- Bibliotheken, Build-Flags und platformio.ini-Import
- Live-Build, Build-Abbruch und Build-Historie
- Projektbackup, Export, Import, Duplizieren und Löschen
- Agent-API einschließlich publishSensor zur Kompatibilität vorhandener Projekte
- USB/OTA-Prototyp, derzeit ohne Hardwaretest

PROBLEM UND LOESUNG 0.5.2
Problem: Eine exportierte Projekt-ZIP konnte ausgewählt und ein Name eingegeben werden, danach gab die Oberfläche weder Erfolg noch Fehler aus.
Loesung:
- Benutzeroberfläche prüft die Dateiauswahl.
- Import läuft in try/catch und zeigt konkrete Meldungen.
- Ein abgeleiteter neuer Projektname wird vorgeschlagen.
- Backend prüft leere, ungültige und beschädigte ZIP-Dateien.
- Backend meldet Namenskonflikte ausdrücklich.
- Import wird atomar über ein temporäres Verzeichnis durchgeführt.
- Nur Archive mit espmanager.yaml im ZIP-Hauptverzeichnis werden akzeptiert.
- Bei Erfolg wird das importierte Projekt automatisch geöffnet.

WICHTIGER HINWEIS ZUM IMPORT
Der Import ist für zuvor durch ESP Manager exportierte Projektarchive gedacht. Ein beliebiges Arduino-ZIP ohne espmanager.yaml ist ein anderer Workflow und muss separat als Arduino-Migration behandelt werden.
